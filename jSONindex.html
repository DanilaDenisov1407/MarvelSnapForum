Клан · история очков

Смотри историю клана из Google Таблицы по тегу или загрузи файл ClanState.json из сохранения Marvel Snap, чтобы увидеть текущие данные и отправить их в историю. Файлы читаются в браузере.

История клана

URL веб-приложения, секретный код и тег клана (например MSF). Те же URL и код используются для отправки данных.

Перетащи сюда ClanState.json или выбери вручную

Текущие данные из файла

Недели отмечены кнопками. Норма проверяется по сумме Bounty + Cube в каждой выбранной неделе. Клик по строке — карточка игрока.

Отправить в историю

Отправит все недели файла с тегом клана из файла. Завершённые недели, уже записанные в таблице, скрипт пропустит, текущую обновит.
